# Wild Season

Wildlife photography holiday planner prototype — filter worldwide photo windows by region, month, style, difficulty, pace, danger, animal type, and rough AUD budget.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Client-side filtering over seeded event data (`src/data/events.ts`)
